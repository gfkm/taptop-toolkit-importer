# Taptop Toolkit Importer

**Расширение для Chrome, которое загружает в редактор [Taptop](https://taptop.pro) страницы, подготовленные [Taptop Toolkit](https://github.com/staumakes/taptop-toolkit).** Вы нажимаете кнопку в редакторе, выбираете файл — и страница появляется: с блоками, текстами, кнопками, картинками и стилями, готовая к редактированию.

*English: a Chrome extension that imports Taptop Toolkit JSON packages (layers, classes and images) into the open Taptop editor.*

В Chrome Web Store расширения пока нет — оно устанавливается вручную из этой папки за пару минут.

Расширение — обязательная часть системы: без него подготовленная страница в Taptop не попадёт. Как работает вся система и что она умеет переносить, рассказано в [README Taptop Toolkit](https://github.com/staumakes/taptop-toolkit).

## Что делает расширение

Когда вы загружаете файл, расширение:

1. **проверяет файл** и показывает, сколько в нём слоёв, стилей (классов) и картинок;
2. **загружает картинки** в медиатеку вашего проекта Taptop;
3. **создаёт стили**, а те, что уже загружались раньше из этого же файла, — обновляет;
4. **вставляет страницу** в конец открытой страницы редактора.

## Установка

1. Скачайте этот репозиторий: зелёная кнопка **Code → Download ZIP**, затем распакуйте архив.
2. Откройте в Chrome адрес `chrome://extensions`.
3. Включите **«Режим разработчика»** — переключатель справа вверху.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку **`src`** внутри распакованного архива.
5. Откройте любой проект в редакторе Taptop. В правом нижнем углу появится круглая синяя кнопка — значит, всё работает.

**Как обновить:** скачайте новую версию и замените ею старую папку. Затем в `chrome://extensions` нажмите на карточке расширения кнопку обновления (круглая стрелка) и перезагрузите вкладку с редактором.

## Как загрузить страницу

1. Откройте в редакторе Taptop страницу, куда переносите.
2. Нажмите синюю кнопку расширения в правом нижнем углу.
3. Выберите файл или перетащите его в окно. Файлы лежат в папке проекта Toolkit: `output/json/`. **Сначала загрузите UI-кит, потом страницы.**
4. Посмотрите проверку: сколько слоёв, стилей и картинок будет добавлено. Стили UI-кита на страницах должны быть отмечены как «уже есть» или «без изменений».
5. Нажмите **«Импортировать»** и дождитесь, пока загрузятся картинки.
6. Проверьте страницу на холстах «Компьютер», «Планшет», «Мобильный горизонтальный» и «Мобильный портретный». Нажмите **Cmd+S** (на Windows — **Ctrl+S**). Значок сохранения должен стать зелёным.

## Полезно знать

- **Страница всегда добавляется заново.** Расширение не заменяет то, что вы вставили раньше, а кладёт новую копию в конец страницы. Старую удалите вручную.
- **Стили обновляются.** Если вы загружаете новую версию того же файла, расширение обновит созданные им стили. Оно запоминает их в браузере, отдельно для каждого проекта Taptop. Чужие стили с таким же названием оно не перезапишет без спроса.
- **Ничего не ломается молча.** Если Taptop не может сохранить какое-то значение так, как оно записано в файле, расширение остановится и скажет, в каком стиле проблема.
- **Понятные ошибки.** Если файл повреждён или Taptop не ответил, расширение объяснит, что случилось, и скажет, успело ли что-то добавиться на страницу.

## Для разработчиков

Нужен Node.js 22 или новее:

```sh
npm ci            # установка
npm test          # тесты
npm run package   # сборка ZIP для Chrome Web Store
```

`npm run package` собирает `dist/taptop-toolkit-importer-<версия>.zip`. В архиве только файлы из `src/`, `manifest.json` лежит в корне. Существующий архив команда не перезаписывает.

- `src/` — всё, что работает в браузере;
- `test/` — тесты;
- `contracts/` — описание формата файлов Toolkit, которое понимает расширение;
- `fixtures/compatibility/` — тестовые файлы, собранные известной версией Toolkit.

Расширение никогда не зависит от папки Toolkit напрямую: формат файлов зафиксирован в `contracts/`, и его обновление — осознанное решение. Подробнее: [совместимость](docs/compatibility.md), [происхождение кода](docs/provenance.md).

Не кладите в репозиторий клиентские файлы, ссылки на редактор Taptop с параметром `access=` и данные импорта из браузера.
