# Taptop Toolkit Importer

**Расширение для Chrome, которое загружает в редактор [Taptop](https://taptop.pro) страницы, подготовленные [Taptop Toolkit](https://github.com/staumakes/taptop-toolkit).** Вы нажимаете кнопку в редакторе, выбираете файл — и страница появляется: с блоками, текстами, кнопками, картинками и стилями, готовая к редактированию.

*English: a Chrome extension that imports Taptop Toolkit JSON packages (layers, classes and images) into the open Taptop editor.*

Расширение — обязательная часть системы: без него подготовленная страница в Taptop не попадёт. Сами файлы для загрузки готовит Taptop Toolkit вместе с ИИ-ассистентом — как это работает, рассказано в [README Taptop Toolkit](https://github.com/staumakes/taptop-toolkit).

## Что делает расширение

Когда вы загружаете файл, расширение:

1. **проверяет файл** и показывает, сколько в нём слоёв, стилей (классов) и картинок;
2. **загружает картинки** в медиатеку вашего проекта Taptop;
3. **создаёт стили**, а те, что уже загружались раньше из этого же файла, — обновляет;
4. **вставляет страницу** в конец открытой страницы редактора.

## Установка

В Chrome Web Store расширения пока нет, поэтому оно ставится вручную. Это займёт пару минут.

1. **Скачайте расширение.** На этой странице нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив. Получится папка `taptop-toolkit-importer-main`.
2. **Положите папку туда, где она будет жить постоянно**, например в «Документы». Chrome берёт расширение прямо из этой папки: если её удалить или переместить, расширение перестанет работать.
3. **Откройте страницу расширений.** Вставьте в адресную строку Chrome `chrome://extensions` и нажмите Enter.
4. **Включите «Режим разработчика»** — переключатель справа вверху.
5. **Нажмите «Загрузить распакованное расширение»** (появится слева вверху) и выберите папку **`src`** внутри `taptop-toolkit-importer-main`. Выбирать нужно именно `src`, а не всю папку.
6. **Проверьте.** Откройте любой проект в редакторе Taptop. В правом нижнем углу появится круглая синяя кнопка — значит, всё работает. Если редактор открывается на собственном домене проекта, а не на `….taptop.site`, один раз разрешите расширению этот домен — см. «Синей кнопки нет» ниже.

Chrome иногда показывает предупреждение о расширениях в режиме разработчика. Это нормально для расширений, установленных вручную: просто закройте его.

**Как обновить:** скачайте новую версию и замените ею старую папку (на том же месте). Затем в `chrome://extensions` нажмите на карточке расширения круглую стрелку и перезагрузите вкладку с редактором Taptop.

## Как загрузить страницу

Toolkit выдаёт как минимум два файла: **UI-кит** (имя начинается с `ui-kit`) и **страницу** (имя начинается с `pages`). Они лежат в папке Toolkit: `projects/<название проекта>/output/json/`. Ассистент подскажет, какие именно файлы загружать.

1. **Сначала UI-кит — на отдельную страницу.** Создайте в Taptop новую страницу, например «UI-кит», и откройте её в редакторе. Нажмите синюю кнопку расширения и выберите файл `ui-kit…json`.
2. **Потом страницу — на свою страницу.** Откройте пустую страницу, куда переносите (например, главную), нажмите кнопку расширения и выберите файл `pages…json`. Файл можно и просто перетащить в окно расширения.
3. **Посмотрите проверку.** Расширение покажет, сколько слоёв, стилей и картинок будет добавлено. Стили UI-кита на страницах должны быть отмечены как «уже есть» или «без изменений» — это значит, страница использует стили UI-кита.
4. **Нажмите «Импортировать»** и дождитесь, пока загрузятся картинки. Не закрывайте вкладку до конца.
5. **Проверьте страницу** на всех холстах — переключаются в верхней панели редактора: «Компьютер», «Планшет», «Мобильный горизонтальный» и «Мобильный портретный».
6. **Сохраните:** нажмите **Cmd+S** (на Windows — **Ctrl+S**). Значок сохранения вверху должен стать зелёным.

## Частые вопросы

**Синей кнопки нет.** Проверьте по порядку:
1. открыт именно редактор Taptop — адрес вида `https://….taptop.site/-/cms/v1/mosaic/…`;
2. если редактор открыт на собственном домене проекта (адрес вида `https://<домен проекта>/-/cms/v1/mosaic/…`), расширению нужно один раз разрешить этот домен: нажмите значок расширения на панели Chrome, затем **«Разрешить на этом домене»** и подтвердите в окне Chrome. Доступ выдаётся только этому домену, кнопка появится сразу, а потом — при каждом открытии редактора. Если после подтверждения кнопки нет, перезагрузите вкладку;
3. в `chrome://extensions` расширение включено;
4. вкладка с редактором перезагружена после установки.

**Как убрать доступ к домену проекта.** Откройте любую вкладку, кроме редактора, и нажмите значок расширения: в списке «Разрешённые домены» нажмите «Убрать» рядом с доменом. Доступ можно убрать и в самом Chrome, в настройках расширения (`chrome://extensions` → «Подробнее»): расширение это заметит и перестанет запускаться на домене.

**Страница появилась второй раз.** Расширение всегда добавляет новую копию в конец страницы и не заменяет старую. Удалите лишнюю копию в слоях Taptop. Стили при этом не дублируются, а обновляются.

**Импорт остановился с ошибкой.** Расширение пишет, что случилось и успело ли что-то добавиться на страницу. Если написано «ничего не добавлено» — можно просто повторить. Если не помогает, покажите сообщение ассистенту в Toolkit.

**Страница не сохраняется.** Нажмите Cmd+S (Ctrl+S) ещё раз. Если Taptop пишет «Не удалось сохранить», покажите это ассистенту — он найдёт причину.

**Работает ли в Яндекс Браузере, Edge, Arc?** Расширение сделано для Google Chrome. В других браузерах на основе Chromium оно может заработать, но там его не проверяли.

**Что расширение может видеть на моём компьютере?** Оно запускается только в редакторе Taptop: на адресах `….taptop.site/-/cms/v1/mosaic/…` и на доменах проектов, которые вы сами разрешили кнопкой «Разрешить на этом домене». Другого доступа при установке расширение не получает. В редакторе оно показывает свою кнопку и больше ничего не делает, пока вы не выберете файл. Картинки уходят только в медиатеку вашего проекта Taptop, в сторонние сервисы ничего не отправляется. Чтобы при повторной загрузке обновлять свои стили, а не создавать новые, расширение запоминает их в памяти браузера.

**Чужие стили не пострадают?** Нет. Расширение обновляет только стили, которые само создало раньше из этого же файла. Если в проекте уже есть стиль с таким же названием, при проверке расширение спросит, что делать: создать для блока копию (так по умолчанию), взять существующий стиль как есть или обновить его из файла. Классы сайта, которые файл использует по имени, оно никогда не меняет и не копирует; если какого-то из них нет в проекте, импорт не начнётся.

## Для разработчиков

Нужен Node.js 22 или новее:

```sh
npm ci            # установка
npm test          # тесты
npm run package   # сборка ZIP для Chrome Web Store
```

`npm run package` собирает `dist/taptop-toolkit-importer-<версия>.zip`. В архиве только файлы из `src/`, `manifest.json` лежит в корне. Существующий архив команда не перезаписывает.

- `src/` — всё, что работает в браузере;
- `test/` — тесты;
- `contracts/` — описание формата файлов Toolkit, которое понимает расширение;
- `fixtures/compatibility/` — тестовые файлы, собранные известной версией Toolkit.

Расширение никогда не зависит от папки Toolkit напрямую: формат файлов зафиксирован в `contracts/`, и его обновление — осознанное решение. Подробнее: [совместимость](docs/compatibility.md), [происхождение кода](docs/provenance.md).

Не кладите в репозиторий клиентские файлы, ссылки на редактор Taptop с параметром `access=` и данные импорта из браузера.
