# Taptop Toolkit Importer

**Расширение Chrome, которое вставляет страницы, подготовленные [Taptop Toolkit](https://github.com/staumakes/taptop-toolkit), в редактор [Taptop](https://taptop.pro).** Оно проверяет JSON-пакет, загружает картинки в медиатеку проекта, создаёт и обновляет классы и вставляет редактируемые слои в конец открытой страницы.

*English: a Chrome extension that imports Taptop Toolkit JSON packages (layers, classes and images) into the open Taptop editor.*

> Статус: ранняя версия `0.2.0`. В Chrome Web Store расширения пока нет — оно устанавливается из этой папки за минуту.

Расширение — обязательная часть системы: без него JSON из Toolkit в Taptop не попадёт. Как работает вся система, какие сценарии поддерживаются и что переносится, описано в README репозитория [taptop-toolkit](https://github.com/staumakes/taptop-toolkit).

## Установка

1. Скачайте этот репозиторий: кнопка **Code → Download ZIP**, затем распакуйте архив (или `git clone`).
2. Откройте в Chrome адрес `chrome://extensions`.
3. Включите **«Режим разработчика»** (переключатель справа вверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку **`src`** внутри репозитория.
5. Откройте проект в редакторе Taptop: в правом нижнем углу появится круглая синяя кнопка импорта.

**Обновление:** скачайте новую версию на место старой, нажмите кнопку обновления на карточке расширения в `chrome://extensions` и перезагрузите вкладку редактора.

## Как импортировать

1. Откройте нужную страницу в редакторе Taptop.
2. Нажмите синюю кнопку расширения и выберите (или перетащите) JSON из папки `output/json/` вашего проекта Toolkit. **Сначала UI-кит, потом страницы.**
3. Расширение покажет проверку: сколько слоёв, классов и картинок. Классы UI-кита на страницах должны значиться как «уже есть» или «без изменений».
4. Нажмите **«Импортировать»** и дождитесь конца загрузки картинок.
5. Проверьте холсты «Компьютер», 768, 480 и 320 и нажмите **Cmd+S**: индикатор сохранения должен стать зелёным.

Что важно знать:

- Импорт всегда **добавляет** слои в конец страницы и не заменяет вставленное раньше. Старую версию страницы удалите вручную.
- Классы, созданные прошлым импортом того же файла, **обновляются**. Расширение запоминает, что оно создало (в памяти браузера для этого проекта Taptop). Чужие одноимённые классы молча не перезаписываются.
- Если Taptop не может сохранить значение так, как его записали, импорт останавливается и называет класс и свойство. Это защита от «тихо сломанной» вёрстки.
- Если файл повреждён или Taptop не ответил, расширение объясняет, что случилось, и сообщает, было ли что-то добавлено на страницу.

## Для разработчиков

Нужен Node.js 22 или новее:

```sh
npm ci
npm test
npm run package
```

`npm run package` собирает `dist/taptop-toolkit-importer-<версия>.zip`: в архиве в корне лежит `manifest.json`, и в нём только файлы из `src/` (без тестов, фикстур и документации); существующий ZIP он не перезаписывает. Совместимость с пакетами Toolkit описана в [compatibility](docs/compatibility.md), происхождение кода — в [provenance](docs/provenance.md).

- `src/` — всё, что работает в браузере;
- `test/` — тесты;
- `contracts/` — зафиксированный снимок контракта пакетов Toolkit;
- `fixtures/compatibility/` — синтетические пакеты, собранные известной версией Toolkit.

Обновление контракта — осознанное изменение совместимости. Во время работы расширение никогда не зависит от соседней папки Toolkit.

Не кладите в публичный репозиторий клиентские JSON-файлы, ссылки на редактор с параметром `access=` и квитанции импорта.
