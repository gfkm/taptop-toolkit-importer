# Архив: ранний план инспектора

Этот файл сохранён как исторический контекст. Описанный в нём сценарий с выбором
папки ресурсов больше не применяется: он относится к пакету версии 1.

Актуальная модель — один JSON версии 2 с `embeddedAssets`. В редакторе
автоматически появляется круглая кнопка над нативным `?`; она открывает единый
диалог проверки и импорта. Транспорт реализован, но живой импорт считается
доказанным только с receipt из disposable-проекта.

Текущий источник правды и фактический статус:
[extension-ui/DESIGN.md](extension-ui/DESIGN.md) и
[compatibility.md](compatibility.md).
