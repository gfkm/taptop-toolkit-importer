# Собственный импортёр пакетов — архив первой спецификации

**Status:** superseded on 2026-10-06. Use
[extension-ui/DESIGN.md](extension-ui/DESIGN.md) and
[compatibility.md](compatibility.md) for current behavior and
proof requirements. This file records a toolbar-triggered prototype; its
claims about disabled transport, session-only injection and a Layers entry
point are obsolete.

## Цель

Создать независимое Chrome-расширение Taptop Toolkit Importer, которое открывает один переносимый пакет Toolkit, проверяет его до записи в редактор и даёт пользователю ясный следующий шаг.

## Выбранная граница

Первый поставляемый слой — проверка одного JSON версии 2 и временная точка входа в Layers. Пользователь открывает редактор, нажимает кнопку в toolbar popup, после чего расширение добавляет синюю кнопку импорта в текущую вкладку. Выбор JSON проверяет формат, версию, встроенные изображения и SHA-256.

Расширение пока не загружает файлы, не вставляет слой и не изменяет буфер обмена. Эти действия будут включены только после отдельного подтверждения нативного пути записи в независимом тестовом проекте. Так интерфейс и формат уже готовы, но неподтверждённый API не выдаётся за рабочий импорт.

## Контекст открытого редактора

Второй подэтап добавляет только проверку вкладки, вызванную кнопкой в popup. Расширение использует `activeTab` и `scripting`: Chrome выдаёт доступ к активной вкладке после явного нажатия, а не постоянно для домена Taptop. Проверка возвращает только hostname, pathname, title и факт наличия видимой оболочки редактора. Она не читает макет, не запускает модули приложения и не записывает данные в страницу.

Эта проверка нужна для будущей диагностической совместимости, а не является доказательством возможности импорта. Реальный путь вставки будет выделен отдельным адаптером только после живого теста в независимом тестовом проекте.

## Структура

- `extension/manifest.json` — Chrome Manifest V3, без host permissions; временный доступ к текущей вкладке выдаёт только `activeTab`.
- `extension/popup/` — первая инструкция и явное действие «Показать кнопку импорта» для текущей вкладки.
- `extension/editor/` — кнопка Layers, карточка выбора одного JSON, нижний индикатор и понятные ошибки.
- `extension/lib/package-inspector.js` — не зависит от DOM: читает File-like objects, проверяет wrapper и asset records, сравнивает SHA-256.
- `extension/lib/editor-context.js` — классифицирует минимальный, read-only ответ текущей вкладки.
- `extension/test/` — Node tests того же инспектора.

## Пользовательский поток

1. Пользователь открывает проект Taptop в редакторе.
2. В toolbar popup нажимает «Показать кнопку импорта».
3. В Layers нажимает синюю кнопку, выбирает один JSON и видит число слоёв, классов и изображений либо ясную ошибку.
4. До живой проверки мостика кнопка «Импортировать» остаётся отключённой. Это защищает проект от частичной вставки.

## Не входит в этап

Загрузка в Taptop, сохранение receipts, конфликты классов, ввод в clipboard, Figma и повторное обновление страницы. Новый импортёр не использует исходники или интерфейс taptop-helper.
