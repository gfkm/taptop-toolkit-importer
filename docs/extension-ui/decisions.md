# Extension UI — журнал решений

| Дата | Решение | Причина |
| --- | --- | --- |
| 2026-10-06 | Постоянный launcher в редакторе над `?` | Chrome action не должен быть обязательным шагом импорта. |
| 2026-10-06 | Все статусы импорта находятся в диалоге | Состояние операции не должно быть разделено между модальным окном и toast. |
| 2026-10-06 | Shadcn preset — референс, не runtime | Расширение внедряется в чужой редактор vanilla-JS слоем; React/Tailwind увеличат риск и вес без продуктовой пользы. |
| 2026-10-06 | Inter и Taptop blue выше Geist/Neutral из пресета | Это утверждённый язык Taptop Toolkit. |
| 2026-10-06 | Пошаговый диалог: файл → проверка → импорт → результат | Утверждён по прототипу `prototype/importer-flow.html`. |
| 2026-10-06 | Название «Импорт JSON», описание «Секция, страница или целый сайт из Toolkit.» | Импортируют и секции, и страницы, и сайты; заголовок называет то, что загружают. |
| 2026-10-06 | Проверка показывает слои, новые/изменяемые классы и изображения | Пользователю важно, что изменится в проекте, а не голые счётчики. |
| 2026-10-06 | Загрузка — кольцо с процентом; заголовок и есть текущий шаг | Вариант A выбран пользователем; без дублирующей плашки. Процент только по реальным событиям. |
| 2026-10-06 | Любой сбой после начала вставки → «Проверьте результат» без «Повторить» | Вставка могла пройти; повтор создаст дубль. |
| 2026-10-06 | UI в closed shadow root, шрифт через FontFace | Стили Taptop не влияют на импортёр; Inter реально загружается. |
| 2026-10-06 | В редакторе иконка Chrome открывает диалог, вне редактора — поп-ап | Поп-ап объясняет, что это и где кнопка. |
| 2026-10-06 | Оверлей диалога светлее Maia: 24% + blur 1px | Пользователь должен видеть, что происходит в редакторе за диалогом. |
| 2026-10-06 | Иконка расширения — стрелка загрузки вместо буквы T | Иконка объясняет действие и совпадает с кнопкой в редакторе. |
| 2026-10-06 | Поп-ап Chrome остаётся системным окном без скруглений | Форму окна задаёт Chrome; своя карточка на странице потребовала бы вмешательства в чужие сайты. |
| 2026-10-06 | Кнопка-лаунчер копирует размер и правый край `.tt-help` Taptop, зазор 16px | Две круглые кнопки читаются как одна колонка. |
| 2026-10-07 | Счётчик загрузки — серая плашка в строке заголовка (вариант A), больше воздуха на экране загрузки | Выбран из `prototype/progress-variants.html`; плашка выровнена по оптическому центру строчных букв по замеру. |
| 2026-10-07 | Конфликтующие классы импортируются копиями (`faq` → `faq-2`), шаг проверки показывает их | Taptop при вставке не меняет существующий класс; «изменятся» было неправдой. |
| 2026-10-07 | Повторный импорт того же файла обновляет его классы на месте (синхронизация из Helper, receipt в localStorage). Для чужих классов с тем же именем — выбор «Копиями / Обновить». Для свойств, изменённых и в Taptop, и в файле — выбор «Оставить мои / Из файла» | Без этого повторный импорт плодил дубликаты, а правки из файла терялись. |
| 2026-10-07 | Шрифты пишутся только именем (`Inter`), без проверки «подключён ли» | Шрифты встроены в Taptop; проверка по загруженным ссылкам давала ложные «не подключены». |
| 2026-10-08 | Список классов при проверке — компактные группы: «Изменены вами», «Обновятся», «Новые», «Без изменений»; имена плашками, до 8 + «+N»; свойства только в подсказке; в строке «Классы» максимум два числа | Перечень свойств и бейдж у каждого класса переносился и не читался на 80 классах. |
| 2026-10-15 | Для чужого класса с тем же именем снова выбор, три варианта: «Копиями» (по умолчанию) / «Существующие» / «Обновить»; сегмент на отдельной строке. Классы сайта из `externalClasses` — группа «Классы сайта»; если их нет в проекте, файл не подходит, имена перечислены | Проверка молча выбирала «Обновить» и переписывала класс во всём проекте; классы сайта нельзя ни копировать, ни менять (контракт C3 форка) |
| 2026-10-16 | Варианты выбора — во множественном числе: «Копиями / Существующие / Обновить», пояснение «Использовать существующие: …»; в красной зоне проверки нет «Ничего не добавлено» (остаётся только в ошибке импорта) | Подпись выбора «Классы с тем же именем» и соседняя группа «Копиями» — во множественном числе; на проверке импорт ещё не начинался |
| 2026-10-16 | Группа «Классы сайта» стоит перед «Без изменений» | Эти имена файл требует от проекта; внизу длинного списка их не видно без прокрутки |
| 2026-10-22 | Редактор на домене проекта включается в поп-апе кнопкой «Разрешить на этом домене»; там же список «Разрешённые домены» с «Убрать» | Репозиторий публичный и не должен называть сайты; Chrome выдаёт доступ к одному домену по клику человека, а не ко всем сайтам при установке. |
